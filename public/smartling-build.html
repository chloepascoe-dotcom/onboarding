Smartling ChatGPT Ads

Step-by-step build instructions for the team

⚠️ Key Constraint: No Conversion Tracking

Conversion tracking is not yet available. Optimize toward engagement metrics (CTR, CPC) and use GA4 traffic quality (time on site, pages/session, bounce rate) as proxy signals. Manually track demo requests attributed to ChatGPT traffic.

Pre-Build Checklist
  • ChatGPT Ads account access confirmed
  • Billing set up with $12.5k monthly pilot budget
  • GA4 access confirmed (for traffic quality analysis)
  • Landing page URLs finalized
  • Brand assets received (logo, colors, guidelines)
  • UTM parameters defined and documented
UTM Convention

Strict UTM structure for all ChatGPT ad links:

?utm_source=chatgpt&utm_medium=paid-ai&utm_campaign=[campaign-name]&utm_content=[ad-variant]
ParameterValue
utm_sourcechatgpt
utm_mediumpaid-ai
utm_campaignchatgpt_highintent / chatgpt_competitor / chatgpt_awareness
utm_contentv1-demo / v2-casestudy / etc.

Optimization Playbook (No Conversions)

Week 1-2: Launch

  • • Launch High-Intent campaigns first
  • • Monitor CTR and CPC daily
  • • Check GA4 for traffic quality

Week 3-4: Refine

  • • Pause topics with CTR <1%
  • • Double down on high CTR topics
  • • Test new ad variants
Signal Good Action if Low
CTR >2% Improve ad copy, refine topics
CPC <$15 avg Shift budget to efficient topics
Bounce Rate (GA4) <50% Check landing page relevance
Time on Site (GA4) >2 min Traffic is qualified
Weekly Reporting

Pull these metrics every Monday:

  • Spend by campaign (vs. budget)
  • Impressions, Clicks, CTR, CPC by campaign
  • Top performing topics (by CTR)
  • GA4: Sessions from utm_source=chatgpt
  • GA4: Bounce rate, time on site, pages/session
  • Manual count: Demo requests (ask sales)
