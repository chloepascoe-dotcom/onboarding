Platform Instructions

G Google Analytics 4

  1. Go to Admin (gear icon, bottom left)
  2. Under Account column, click Account Access Management
  3. Click the + button, then Add users
  4. Enter: analytics@singlegrain.com
  5. Select role: Editor
  6. Click Add
  7. Repeat for: adwords@singlegrain.com
Note: Grant access at the Account level (not Property level) so we can see all properties.

T Google Tag Manager

  1. Go to Admin
  2. Under Account, click User Management
  3. Click + then Add users
  4. Enter: analytics@singlegrain.com
  5. Set Account Permissions to Admin
  6. Set Container Permissions to Publish
  7. Click Invite
  8. Repeat for: adwords@singlegrain.com

S Google Search Console

  1. Select your property in Search Console
  2. Click Settings (gear icon)
  3. Click Users and permissions
  4. Click Add user
  5. Enter: analytics@singlegrain.com
  6. Select permission: Full
  7. Click Add
Note: We do not need Property Owner access. Full User access is sufficient.

A Google Ads

  1. Sign into Google Ads
  2. Locate your Customer ID (top right corner, format: XXX-XXX-XXXX)
  3. Send the Customer ID to your Single Grain contact
  4. We will send an access request
  5. You'll receive an email from Google - accept the request
Alternatively: Go to Tools & Settings > Access and security > Add user > Enter adwords@singlegrain.com with Admin access.

M Google Merchant Center

  1. In Merchant Center, click Settings (gear icon)
  2. Select Account access
  3. Click Add user
  4. Enter: analytics@singlegrain.com
  5. Set access level: Admin
  6. Click Add user

M Meta (Facebook/Instagram) Ads

Must be done on desktop, not mobile.

Option A: Accept Partner Request (Preferred)

  1. Go to Business Settings at business.facebook.com
  2. Click Partners in left menu
  3. Look for pending request from Single Grain
  4. Accept with Full Control access

Option B: Send Partner Invite

  1. Go to Business Settings
  2. Click Partners > Add
  3. Enter Single Grain Business ID: 10152546861047072
  4. Grant Full Control to:
    • Ad Account(s)
    • Facebook Page(s)
    • Instagram Account(s)
    • Pixel(s)
Important: We need access to the Page AND Ad Account AND Pixel to run campaigns.

in LinkedIn Ads

If you have Business Manager:

  1. Sign into Business Manager
  2. Click Partners in left menu
  3. Click Add partner
  4. Enter Single Grain Partner ID: 7186746961612406786
  5. Click Share ad accounts and select accounts to share
  6. Assign highest available role
  7. Click Share Pages and grant page access

If you only have Campaign Manager:

  1. Find your Ad Account ID (9-digit number under account name)
  2. Send the ID to your Single Grain contact
  3. We will request access - approve when you receive the notification
Note: We need both Ad Account access AND Page access to create ads.

B Microsoft (Bing) Ads

  1. Sign into Microsoft Ads
  2. Click Tools > Account access
  3. Go to the Users tab
  4. Click Invite user
  5. Enter: adwords@singlegrain.com
  6. Select role: Super Admin
  7. Click Send

T TikTok Ads

  1. Log into TikTok Business Center
  2. Click Users > Partners in left menu
  3. Click Add Partners
  4. Enter Single Grain Business Center ID: 6998239304547909634
  5. Click Next
  6. Select ad accounts to share
  7. Assign Admin role
  8. Click Confirm

P Pinterest Ads

  1. Log into Pinterest Business account
  2. Click dropdown arrow (top-right) > Business Access
  3. Click Partners in left menu
  4. Click Add partner
  5. Enter Single Grain Business ID: 794322590436195524
  6. Select Invite a partner to access your assets
  7. Assign ad account access

S Snapchat Ads

Two-step process: Organization first, then Ad Account.

Step 1: Organization Access

  1. Log into Ads Manager
  2. Click menu (top left) > Members
  3. Click + Invite Member
  4. Enter: adwords@singlegrain.com
  5. Set Organization Role: Business Admin

Step 2: Ad Account Access

  1. In Members, select adwords@singlegrain.com
  2. Under "Account Memberships", select ad account(s)
  3. Assign role: Account Admin

R Reddit Ads

  1. Log into Reddit Ads
  2. Click menu (top left) > Users
  3. Click + Invite New Members
  4. Enter: adwords@singlegrain.com
  5. Set Business Role: Member
  6. Click Next
  7. Select the ad account to grant access
  8. Set Ad Account Role: Administrator
  9. Click Done

X X (Twitter) Ads

  1. Log into ads.twitter.com
  2. Click your account name (top right)
  3. Select Edit access to account
  4. Click Add access
  5. Enter Single Grain handle: @singlegrain
  6. Select access level: Ad Manager
  7. Click Save changes

a Amazon Ads

Instructions vary based on account type:

  • Vendor Central: Follow these instructions
  • Seller Central: Follow these instructions

Add: adwords@singlegrain.com

Apple Search Ads

  1. Sign into Apple Search Ads
  2. Go to Settings > User Management
  3. Click Invite User
  4. Enter Apple ID: analytics@singlegrain.com
  5. Name: Single Grain
  6. Grant Admin access

S Shopify

  1. From Shopify Admin, click Settings > Users and permissions
  2. Click Add staff
  3. Enter:
    • Full Name: Single Grain
    • Email: operations@singlegrain.com
  4. Grant all available permissions
  5. Click Send invite

C CRM Access

Grant access to: adwords@singlegrain.com

Common CRMs:

  • HubSpot: Settings > Users & Teams > Create user
  • Salesforce: Setup > Users > New User
  • Pipedrive: Settings > Manage users > Add user
Why we need CRM access: To set up offline conversion tracking, validate lead quality, and optimize campaigns based on downstream metrics (MQL, SQL, closed revenue).
